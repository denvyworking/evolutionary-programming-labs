# Лабораторные работы №1 и №2

Реализация вещественного генетического алгоритма для многомерной оптимизации
функции Альпина №1 (индивидуальный вариант `V=11`, `d=10`).

## Лабораторная работа №1

## Требования

- Python 3.10 или новее;
- используются только стандартные библиотеки Python;
- готовые пакеты оптимизации не используются.

## Запуск

Один воспроизводимый запуск:

```text
python lab1_ga.py
```

Полная серия экспериментов (20 seed, две конфигурации ГА и случайный поиск):

```text
python lab1_ga.py --run-experiments
```

Результаты появятся в каталоге `results/`: `results.csv`, `trajectory.csv` и
`convergence.svg`. Параметры зафиксированы в `config.json`.

## Лабораторная работа №2

Вариант `V=11`: задача коммивояжёра на 20 синтетических городах. Используется
перестановочное представление маршрута, кроссоверы OX и PMX, мутации обменом и
инверсией. Данные и параметры зафиксированы в `lab2_config.json`.

```text
python lab2_tsp.py --run-experiments
```

Подробный отчет находится в `REPORT_LAB2.md`, а результаты экспериментов,
таблицы и графики — в `lab2_results/`.
